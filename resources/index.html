HOW TO USE THESE SOURCES

Don't try to memorize the rules. Build evidence.

01

Read Publication 5708

Start with the resource written for tax and accounting practices so the subject is grounded in your industry.

02

Compare the FTC elements

Use the FTC guidance to understand the broader structure of a written information security program and the controls that need to be maintained.

03

Verify your implementation

For each statement in the WISP, ask what real evidence proves the safeguard exists and is maintained.
